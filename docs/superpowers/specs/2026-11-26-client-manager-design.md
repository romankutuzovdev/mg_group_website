# Назначение менеджера клиенту

Любой менеджер может забрать самостоятельно зарегистрировавшегося клиента и
переназначить любого клиента другому менеджеру. Право любого менеджера подтверждено
пользователем. Все клиенты по-прежнему видны менеджерам.

## Подход

Использовать существующие поля `users.manager_user_id` и
`deals.created_by_user_id`, которое уже служит ответственным по сделке.
В одной транзакции менять назначение клиента и всех его сделок. Смена только
клиентского поля оставила бы прежнему менеджеру право редактировать сделки.
Новая таблица назначений для этого изменения не требуется.

## Правила

- В карточке клиента: «Забрать себе» и «Сменить менеджера» с выбором сотрудника.
- Назначать можно менеджера или администратора, но только обычному клиенту.
- Клиент и логист не могут менять назначения. Роли сотрудников не меняются.
- При устаревшем назначении возвращать 409 и обновлять список.
- После передачи новый менеджер редактирует сделки, прежний сохраняет просмотр.
- Существующие данные, пароли и содержимое сделок сохраняются; миграции нет.

Перенос всех сделок и проверка конкурирующих изменений — решения реализации.
